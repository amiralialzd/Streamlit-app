# SpaceX Launch Success Predictor

An interactive ML web app that predicts SpaceX Falcon 9 booster landing success 
by launch site, payload mass range, and classification model.

**Live App:** https://app-app-tvrvkngzsyzte6wlprytah.streamlit.app/



## What it does
- Filter launches by site (CCAFS SLC 40, KSC LC 39A, VAFB SLC 4E, or ALL)
- Adjust payload mass range with an interactive slider
- Switch between DecisionTreeClassifier and KNeighborsClassifier
- View success rate pie chart, payload vs outcome scatter plot, and confusion matrix

## Tech Stack
Python · Pandas · Scikit-learn · Plotly · Streamlit
